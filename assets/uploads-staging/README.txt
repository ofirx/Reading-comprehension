Drop your While reading files here, then run Auto save to GitHub.bat (or auto-save-to-github.ps1):

  listening-text.txt     — text for the listening panel
  listening-audio.mp3    — audio file (mp3, wav, ogg, or webm also work)

You can use any name starting with listening-audio (e.g. listening-audio.wav).

The script copies files into assets/uploads/, updates services.html, and pushes to GitHub.
