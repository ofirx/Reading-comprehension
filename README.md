# EFL-Style Website Template

This is a simple multi-page static template (plain HTML + CSS).

## How to run
Open `index.html` in your browser.

## Pages included
- `index.html` (Home)
- `about.html` (About)
- `services.html` (Services)
- `contact.html` (Contact)

## Assets
The hero background references `assets/hero.jpg`.

Place an image at:
- `assets/hero.jpg`

If you want to use the screenshot image you provided, copy/rename it to `assets/hero.jpg`.

## Add your own pages
Duplicate one of the existing HTML files and update:
- the `<body data-page="...">` value
- the hero text
- the main section content
